
Frontend application for managing coupons, built with React.

## 🚀 Project Overview
This project is a client-side web application for managing coupons.
It includes authentication, role-based access, coupon creation and viewing,
and a modern responsive UI.

## 🛠️ Technologies
- React
- JavaScript / TypeScript
- HTML5 & CSS3
- Tailwind CSS
- Axios
- Git & GitHub
